# Preview.6.2.1 发送、日志与背景修复

本版继续使用 preview.6 的界面基线，不合入 preview.6.1 改版。版本代码 13，可覆盖安装同签名旧版。

## 修复

- **发送后只剩背景**：真实 SQLite 复现发现，preview.6.2 给纯文字回复的 JSON 图片字段默认填入 `{}`，前端调用 `.map()` 导致 React 整页卸载。现在数据库字段明确以空数组初始化，角色回复和开场白显式写入空数组，历史接口与前端统一兼容旧对象、空值和非法附件项。旧聊天内容不删除。
- **日志深色模式看不清**：原日志背景依赖系统的深色媒体查询，App 手动选深色时可能保留浅色背景。日志与诊断面板现在统一读取 App 主题的背景和文字变量，字号调整到 12 px。
- **背景上传后无法确认显示**：原先通过桥接返回完整 Base64 大图，再用带 filter 的 CSS 背景层渲染。现在原生层返回私有资源文件路径，由 Capacitor 本机文件服务读取；背景作为 App 外的独立全屏图片层显示。选图后重新读取已保存资源，显示缩略预览和成功提示，更换图片携带文件修订号避免缓存旧图，加载失败给出提示。字体资源也改走本机文件服务。

## 验证

- 真实 Koishi/HDS/SQLite 测试覆盖角色文字回复、旧 `{}` 图片字段、重启后历史读取与图片发送。
- 浏览器回归包含文字和图片回复、旧对象字段、导航持续存在、真正解码的背景图、视口覆盖、更换后的缓存修订号及重载后持久显示。
- 手动深色主题在系统浅色下验证日志文本对比度至少 4.5:1。
- Android 编译、签名 APK 与 ARM64 / PRoot / QQ 检查通过仓库 Actions 构建验证；自动化回归不等于真机实测。

覆盖安装后，首次唤醒会更新内嵌核心。已有聊天、角色和模型设置保留；旧背景文件也继续读取，无需清除应用数据。
