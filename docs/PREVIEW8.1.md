# Preview 8.1 · 图片提示、定时联系与阅读体验修复

版本：0.1.0-preview.8.1，versionCode 17。基于 main `9091246` / HDS rc51。

## 改动内容

### 图片

- 聊天输入框「＋」不再静默失败：识图未开启、模型不支持视觉、图片过大等五类原因均有明确文字提示；识图未开启时提示前往「空间 → 模型与识图」开启图片理解（识图模型），并保留跳转设置页。
- 相册支持一次勾选多张（最多 3 张）：原生图库经 `EXTRA_ALLOW_MULTIPLE` + `clipData` 全量收图，不再"选了多张只进去一张"。
- 重启判定改用运行中真实配置比对，避免"改了点无关设置就提示重启"的误报。

### 定时联系

- 新增 scheduled-contact 约定类型：角色按约定时间主动发消息，投递成功（含回执确认）才算完成。
- "七分钟后提醒我""半小时后叫我"这类相对时间精确到秒（中文数字、口语时钟均可解析）；时间不明确时明确说明原因并写入待办，不假装成功。
- 新消息不再静默取消显式约定；承诺的时间下限可配置。

### 聊天与见闻

- 翻看旧消息不再被强制拉回底部，新消息以角标提示。
- 消息发送状态可见（发送中 / 已送达 / 失败），失败可一键重试。
- 见闻、长期记忆、当前心绪切换后保留各自的滚动位置；snapshot 读取单飞去重。

### 日志与大图

- 默认日志级别提升至 info，排查问题更直观。
- 大图发送改为流式落盘与处理，降低内存占用峰值，减少闪退。

## 实现与验证

关键实现：`packages/contracts/index.ts`（imageEntryReason 提示文案与约定类型定义）、`apps/mobile-ui/main.tsx`（多选与跳转控制）、`runtime/host.ts`（定时联系与滚动/见闻逻辑）、`android/app/src/main`（原生图库多选）、`tests/scheduled-contact.test.ts` 与 `tests/qq.test.ts`（投递回执）。

- 发布 CI（run [38782315234](https://github.com/sl251/HDS-Android/actions/runs/38782315234)）：云端独立 `npm test` 46/46 通过、lint、release 单测、签名 APK 构建成功；下载后 `sha256sum -c` 与 apksigner 校验一致。
