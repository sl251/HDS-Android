# HDS Android 0.1.0-preview.1 真机测试

这是第一个可安装的开发预览包，不是已通过全部验收的完整移植版。真机运行由你验证；本次自动化测试使用固定模型响应，不冒充真实 API 或 Android 结果。

## 安装与首次使用

1. 下载 `HDS-Android-0.1.0-preview.1-arm64.apk`，在 ARM64、Android 8 或以上手机安装。安装包使用本项目自己的固定预览签名，不需要电脑或 Termux。
2. 打开“角色”，导入提供的合成 JSON 样例或自己的 Tavern JSON/标准 tEXt PNG 卡；检查预览再保存。也可手动创建。
3. 打开“设置”，点击“准备本机环境”，等待 APK 内置 Ubuntu/Node/HDS 校验和解包。确保可用空间满足应用显示的实际需求。
4. 填写完整的 OpenAI 兼容 Chat Completions 请求地址、模型名称、API Key，并填写你的故事称呼/人设。保存连接，再按“测试已保存连接”；这一步真的调用 API，可能有少量费用。
5. 点击“启动 HDS”。状态只有在手机里的 Node/Koishi/HDS/SQLite 认证健康接口实际响应后才显示“运行中”。失败时展开日志，不会用假回复替代。
6. 在“对话”发送一句话，等待 HDS 生成。去“动态”刷新真实剧情与长期事实。角色卡开场白会在本地展示、入账，不会向 QQ 发送。
7. 切换另一个角色会先停止旧运行档案。重新启动后生成独立故事；切回时旧数据库保留。不要通过卸载应用来重装环境，卸载会删除本机故事。

## 推荐按顺序测试

| 测项 | 操作 | 记录 |
| --- | --- | --- |
| 安装 | 第一次打开、离线打开、取消文件选择后再次导入 | PASS / FAIL；截图或错误 |
| 环境 | 解包、空间不足、安装中切后台、重开后重试 | 阶段与错误日志 |
| 启动 | 先不配模型，再保存有效模型启动 | 健康状态、耗时、页大小 |
| 对话 | 连续 5—10 轮；短时间连续发两句；分段回复中发新消息 | 实际回复与模型名称 |
| 角色 | 两个角色切换 A→B→A；重复导入同一文件 | 历史是否隔离/保留 |
| 卡上下文 | 卡中加入明显人设、对话示例和关键词世界书 | 是否影响请求与回答 |
| 停止恢复 | 正常停止后重启、关应用界面、系统强停后重新打开 | 数据是否保留；强停期间不应继续运行 |
| 后台 | 关屏 10 分钟、关闭省电限制前后、开启持续生活 | 通知、进程、API 用量、是否中断 |

默认关闭持续生活与主动联系。开启后按 HDS 原有调度运行，可能持续产生 API 费用；前台通知不保证免于 Doze、厂商回收或系统强停。

## 已知边界

- 只包含 ARM64 运行器；4 KB/16 KB 页、iQOO/OriginOS 和后台策略均未实测。无法启动请反馈 ABI、页大小、Android/API 与日志。
- QQ 私聊、群聊、空间读/发帖/评论/点赞均未接入，本版不会称这些功能“已支持”。未打包 Linux QQ 或 SnowLuma；完整首版门槛仍未通过。
- 角色卡 V1/V2/V3 JSON 与标准 tEXt PNG；原始字节和未知字段保存。CHARX、iTXt/zTXt、V3 外链资源、扩展脚本、正则与递归世界书执行未完成。
- 世界书支持关键词、secondary/selective、常驻、禁用、大小写、顺序/优先级、前后位置和保守预算。暂不等同 SillyTavern 完整提示编排。
- 备份/恢复、电脑迁移、升级回滚、媒体、浏览器、完整高级设置与费用预算仍待实现。本版不要用于唯一副本的重要长期故事。
- 正常停止会请求核心退出；超时后只结束本应用创建的 PRoot 进程。停止/进程回收边界和未知投递恢复仍需要真机故障测试。
