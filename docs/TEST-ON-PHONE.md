# HDS-Android Preview 9.4 真机验收清单

当前验收版本：`0.1.0-preview.9.4`（Android 8.0+ / ARM64）。此清单用于**人工真机验证**，模拟响应和 CI 通过不能替代实际 API、QQ 和 TTS 验收。

## 准备与升级
- 从 [Preview 9.4 Release 或最新预览页](https://github.com/sl251/HDS-Android/releases) 下载 APK，记录手机型号、Android/厂商系统版本、ABI、可用空间和此前的 APK 版本。
- 有旧数据时先导出角色的**完整故事 ZIP**，保存到应用外部位置，再覆盖安装；**不要卸载重装**，否则应用私有数据可能被清空。
- 准备独立测试角色；真实模型请求和 MiMo 试听可能产生费用。QQ 使用自己愿意承担协议及账号风险的测试账号。
- 每项记录 PASS / FAIL / NOT RUN，并保存脱敏日志。真机未执行的项目不得勾选通过。

## 一、安装、运行与界面
- [ ] 首次安装、环境准备、首次唤醒：HDS 与 SQLite 正常启动；失败时显示具体日志和恢复入口。
- [ ] 旧版覆盖升级：角色库、人设、故事、记忆、设置和密钥存在状态保留；重启 App 再检查。
- [ ] 休眠后重启、切换两个角色：聊天与故事互不串用，不重复发送开场白。
- [ ] 在窄屏、输入法弹出、前后台切换和锁屏 10 分钟后测试：底栏及输入区未被遮挡；注意 Android 省电策略可能中断后台服务。
- [ ] 网络中断或空间不足时，安装/恢复操作给出可理解的失败提示，不宣称成功。

## 二、模型、聊天和记忆
- [ ] 在「空间 → 模型与识图」配置主叙事、记忆处理、Alter 等模型，执行连接测试，检查切换和错误反馈。
- [ ] 连续多轮文字聊天，检查流式显示、回复失败/重试、历史加载和重启后内容。
- [ ] 给支持图片的模型发送图片；另测无识图能力或独立识图模型配置下的反馈。
- [ ] 在「见闻」修改事实、记忆和待办，再唤醒，核对角色隔离及状态一致性。
- [ ] 有意开启持续生活/主动联系时检查请求次数、预算及后台行为；默认关闭状态不应自动产生模型调用。

## 三、角色库、分享码及独立导入导出
- [ ] 通过分享码、SillyTavern PNG/JSON、HDS/typ0 YAML 导入角色，检查名称、开场白和世界书。
- [ ] 反复导入同一角色，检查已有编辑不被意外覆盖；不唤醒故事时角色仍可在角色库显示。
- [ ] **不唤醒故事**直接导出原格式 JSON、SillyTavern V2 JSON、HDSI 预设 JSON、YAML 四种格式。
- [ ] 通过 Android 系统文件保存位置选择器保存导出文件，取消操作后不误提示成功；测试「复制内容」和重新导入。
- [ ] 检查导出内容不含已识别连接凭据；分享前仍需检查自由文本中的私人信息。

## 四、完整 ZIP 故事存档
- [ ] 用专用测试角色产生聊天、图片和记忆后，在「空间 → 备份与恢复」导出完整 ZIP，确认文件存放在应用外部。
- [ ] 重开测试角色，确认本机最近备份可恢复；从 ZIP 恢复后消息、图片、事实与暂停状态合理。
- [ ] 使用错误角色存档、取消系统选择器、模拟中断；不应悄悄覆盖其他角色的数据。
- [ ] 确认故事 ZIP 不包含 API Key 或 QQ 登录凭证；这些需要独立保存/重新登录。

## 五、表情包与实验性语音
- [ ] 多选图片或整文件夹导入 PNG/GIF/WebP/JPEG，检查去重、包名、导入数量、动图展示与格式失败提示。
- [ ] 改名、删除单张贴纸和整包，重新唤醒后检查可选清单；已发送表情不应随包删除而消失。
- [ ] 表情库为空时正常纯文字聊天；触发表情时避免同一回复重复发送文字、图片和语音。
- [ ] 在音色工作台配置 MiMo 密钥，尝试描述设计、录音及 WAV/MP3 参考音频导入，试听、保存、绑定、改名和删除音色。
- [ ] 打开角色语音，在触发时检查播放气泡、可展开文字稿以及成功回复不重复附加文字。
- [ ] 关闭语音、断网、TTS 失败或到达 token 日限时，普通文字聊天继续可用；录音和实际 MiMo API 需要真机验证。

## 六、本地 QQ 接入（实验性）
- [ ] 在「信箱」准备 QQ 组件、扫码并登录，用实际收发检验连接，而不只看在线指示。
- [ ] 自动回复保持默认关闭时，验证无未经授权的模型回复；添加好友/群白名单后再逐项打开。
- [ ] QQ 私聊发文字并收到正确回复，确认历史、重复发送防护、重连后的投递情况。
- [ ] QQ 群分别测试普通消息、**@ 账号消息**、引用回复和群规则；只在符合白名单与 @ 门禁时尝试回复，记录未回复时的相关设置及脱敏日志。
- [ ] 测试群表情包格式和可选语音、登录掉线/重连、切后台、停止核心后的行为；实验性能力的失败与账号风控风险应单独记录。
