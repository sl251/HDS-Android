# 9.6.2 生图配置拦截修复（2026-10-24）

基线：`18cf40c`，分支：`codex/fix-image-generation-diagnostics`。本次补丁纳入 **9.6.3**；发布说明见 [PREVIEW9.6.3.md](PREVIEW9.6.3.md)。下文保留修复时的验证记录。

用户报告切换 Gemini 或免费渠道、新生成和原任务重试均出现 `media_configuration`。检查发现，原实现会在整个任务启动前比较旧渠道和当前渠道，即使任务尚未提交，或者只需下载已经生成的图片，也会被拒绝。此外，明确被服务拒绝的自主生图仍占用冷却时间，阻止后续生成。

## 修改

- 未提交的排队任务在执行时使用当前设置，并更新无密钥的渠道快照。
- 已提交的 Imagefree 任务继续查询原渠道；已知图片地址直接下载，不受当前渠道是否启用影响，不会携带新渠道的密钥。
- 旧配置检查失败任务可以通过原有重试入口恢复；有任务编号或图片地址时不再发送生成 POST。
- 明确未提交或被服务拒绝的自主生图失败不消耗冷却；成功、在途或提交结果未知的任务仍有冷却和防重复提交保护。
- 重启时，带有提交标记但没有结果的排队任务转为 unknown，避免误重复提交。
- 历史配置错误的诊断建议改为重试任务，避免提示用户来回切换渠道。
