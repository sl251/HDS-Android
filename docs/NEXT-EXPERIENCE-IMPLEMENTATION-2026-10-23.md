# HDS Android 体验更新实施记录

更新日期：2026-10-23。本次发布为 Preview 9.6，合入 Preview 9.5.3 基线，保持 HDS rc57。本记录区分已经修改的代码、已经验证的行为与仍需设备验证的部分；设计文档中的可选扩展不等于本次全部实现。

## 已实现的交互

- 「聊天与输入」集中管理流式、回车发送/换行、连续消息合并等待和动态开关。流式和合并等待从高级设置移除，高级页保留跳转。JSON 兼容模式与流式的互斥关系明确提示。
- 流式只展示对话正文，不暴露剧本、内部状态或未完成的 JSON；最终回复复用气泡编号。断流保留半段回复，可从原消息重试。已显示的回复不会因后台剧本收尾失败重复发送。
- 发送失败与结果未知的消息使用原请求编号恢复，发件记录按故事保存在本机。模型回复失败重试不会重复写入用户消息。连续输入沿用上游 TurnEngine 的等待、合并和过期回合处理。
- 聊天扩展菜单提供相册、系统相机、语音录音和角色外观入口。录音支持点按与按住说话、上滑取消、试听；可准备语音消息，或通过 STT 转成文字后编辑。未转写的录音有明确标记，不让角色假装听懂。
- 底部导航为故事、见闻、动态、空间。信箱与 QQ 保留在「空间 → 信箱与外部连接」。底部光条限制在选中的导航格内。
- 动态按故事隔离，用户与角色可以发动态、点赞和评论；角色上下文包含点赞/取消点赞及评论变化。角色可不回应。用户发帖或评论后最多安排一次有限重试的观察机会，点赞不额外触发模型调用。
- 「分享此刻」默认折叠，草稿按故事保留，发布成功后收起。删除界面上“角色会看见你的互动，也可以选择不回应”的常驻提示。
- 通知支持悬浮弹窗、通知栏、静默、内容预览、应用内横幅和自定义安静时段；是否悬浮、声音和振动最终遵循系统通知渠道。重复的系统设置按钮已合并。
- 设置卡片增加内边距；视觉档案显示当前角色名称。外观增加晴空蓝、松叶绿、蔷薇粉、暮光紫、暖茶棕，配合浅色/深色/系统模式。表情包管理使用相同主题变量，并精简重复说明。

## 生图与头像

聊天自拍和动态配图由角色自主决定，用户不需要填写生图提示词。模型提交可选的 `mobileActions`，由宿主在正式剧本提交后处理；当前故事、能力开关、意愿阈值、冷却、并发和动作编号共同控制执行。配图成功后才发布动态或发送图片，失败不会阻断普通文本回复。

「空间 → 角色视觉档案」提供固定外观、画风、常用衣装、画面约束、比例与最多三张参考图。外观与画面风格随任务保存，任务不保存 API Key。Imagefree 使用文字约束；兼容服务启用参考图时使用 `images/edits`。文字约束不能保证每张图都拥有完全一致的脸，参考图能力也取决于服务端。

「空间 → 角色头像」是独立入口，支持从本机相册上传任意喜欢的图片与“按人设生成”。头像用于聊天与动态的个人头像，与角色形象档案独立保存；上传、更换或移除头像不会修改生图外观设定，也不会自动加入参考图。头像生成读取当前故事的人设及视觉档案，使用方形画布，完成后需要用户点击“使用这张头像”，不会自动替换已有头像，也不会成为聊天消息或动态。头像保存在故事目录，随现有故事备份归档；不同故事互相隔离。未设置头像时，聊天保持原布局。

媒体任务保留提交、查询、下载、投递状态。未知的服务端接收结果不会自动重新提交；已有任务编号可以继续查询。Imagefree 可能要求站点验证，当前实现不会绕过验证或自动转到付费渠道。尚未用真实服务凭据测试 STT、图片生成及参考图接口。

## 其他修复

- 天气缓存按实际坐标隔离，并约束地点与有效期，避免同名城市或切换地点时取到另一处缓存。设置可查看实际解析地点、坐标及最近状态。
- 录音副本进入故事目录，恢复备份后原生播放可从故事目录补回，避免历史消息只剩文字稿。
- 动态上下文限制事件及评论长度，优先保留最近互动的帖子，避免不断增长的动态占满模型上下文。
- 新媒体密钥在 Android 本地加密，公共设置只返回是否存在；运行日志脱敏包含新媒体服务密钥。
