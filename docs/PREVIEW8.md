# Preview8 · 生活节奏、分享码与后台预算

版本：0.1.0-preview.8，versionCode 16。基于 main `a4a31a0` / HDS rc51。

## 使用

空间 → 生活节奏与表达：支持固定节奏、Urge 弹性推进、Agency 主动联系、日程预排、时间导演、QQ 群聊引用、Alter 情绪参数、记忆整理参数。默认沿用电脑版值，旧版升级不会自动开启 Urge/Agency；在“故事与身份”开启持续生活总开关，再按需启用它们。

Urge 开启时替代固定补写时间点；关闭后恢复自定义补写（未设置则 10/20 分钟）。总开关关闭时 Urge、Agency、时间导演与自动生活推进停用；日程和记忆自身开关独立。输入离焦后保存，点击“立即重启生效”。

分享码入口：唤醒故事 → 输入 typ0.space 分享码 → 检查差异 → 应用到生活设置 → 等待自动保存 → 重启。应用前再次验证远端 revision 和内容指纹；远端变化需重新检查。同步中修改设置会保留本地编辑并要求重查。仅支持字段能应用，模型/密钥/人设/总开关/预算/QQ 空间不会被预设覆盖，忽略字段会列出。没有启用无人值守自动更新。

## 预算

- 默认每滚动 24 小时 120 次后台模型 HTTP 尝试，可调整为 0—10000；0 表示不限。
- 自动写作、时间导演、记忆整理、情绪分析和识图等辅助调用计入；请求发出前预占，失败与重试也计入，流式和非流式一致。
- 直接聊天主叙事、用户手动整理豁免。辅助识图即使由聊天触发也保守计入，因此额度用完时建议继续文字聊天。
- 达限停止新后台模型传输；设置页显示用量和恢复时间，前台通知约每 60 秒更新预算状态。通知权限拒绝不影响聊天。
- 记录保存在公共 QQ 数据目录，切换角色、重启核心或恢复故事存档不清零。它不是金额/token 上限；QQ 轮询与已决定消息的投递不计入。

## 实现和验证

`runtime/mobile-config.ts` 维护支持字段白名单；上游 Schema 生成 `packages/contracts/mobile-config.schema.json` 与 Android 同名 asset。React、原生验证和宿主共用字段定义；runtime 继续用 HDS.Config 补齐其他默认值。构建时自动重新生成 schema。

本地验证：

- 移动端宿主 34 项回归全部通过，包含真实 Koishi/SQLite、预算耗尽、重启保留、主开关与自定义补写、预设清洗/修订冲突、QQ 引用实际 OneBot payload。
- UI 回归覆盖自动保存、模型设置保留、预设检查/应用、320/390/740 px 和浅深色。原生调用为 fixture，不能替代真机。
- Android `MobileSettingsCodecTest` 验证升级默认值、往返、类型/范围和越权字段拒绝；由发布 CI 执行。
- 上游 837 项：830 通过、3 失败、4 跳过。3 项均在未修改的 main 模型源码下复现：configuration 测试仍断言 rc50、release-consistency 日志文档仍写 rc50、fixes-review 的旧假对象缺少 flushBufferedNarrativeBody。没有改断言伪造通过。

发布须以 GitHub Actions 的 Android 编译、lint、单测、签名 APK，以及 Linux ARM64 / PRoot / QQ 用户空间检查结果为准；发布资产另附校验和。
