# Preview.6 · 让故事在当前页面继续

本次改版围绕故事体验整理操作流程，保留原版 HDS 与本机运行架构。

- **故事**：角色名打开故事选择器；点击唤醒会自动准备缺失、过期或需要修复的核心组件，完成后继续启动。进度在原位展示，健康检查通过后聚焦输入框。休息时也可以写草稿。
- **见闻**：独立入口承载故事时间线、长期记忆和核心已有的心理状态记录，运行时每 5 秒刷新。没有记录时显示空状态，不生成示例内容。
- **信箱**：保留 QQ 接入与收信能力。
- **空间**：集中管理角色、模型和故事偏好；组件重新准备与设备诊断收入高级折叠区。
- **模型分工**：主叙事、记忆压缩、心理分析分别选择连接。辅助任务默认沿用主叙事，切换主模型时一同调整。旧版多模型分工保留；备用任务与排序可在高级连接设置修改。删除连接时会为孤立任务选择剩余启用连接；没有可用连接时提示补全。
- **自动保存**：文本失焦保存，选择项短暂合并后保存。原生层继续验证并加密密钥，校验失败的草稿保留并明确显示未保存。保存串行执行，不覆盖保存期间的新输入。未填完的表单需要补全后才能持久化。
- **配置生效**：本版运行参数仍由宿主启动时载入；保存后提供“立即重启生效”，自动停止、启动并保留剧情与记忆。未宣称热更新或零中断。已有故事的初始人设仍按原有规则保留。

## 验证

- `npm test`：23 项通过，包括真实 HDS / SQLite / OneBot 链路与新增任务分工回归。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- 另开终端运行 `npm run dev` 后执行 `npm run test:ui`：验证唤醒进度、聚焦与草稿、四入口导航、模型分工、保存并发、保存失败重试、重启顺序、角色切换以及 320 / 390 / 740 px 布局和深色模式。默认使用本机 Edge；其他浏览器设置 `HDS_BROWSER` 为 Chromium 可执行路径，端口可通过 `HDS_UI_URL` 指定。
- UI 测试使用显式原生桥接夹具，不代表 PRoot 在手机上运行成功。截图保存在忽略目录 `artifacts/`。

## 真机验收

1. 全新安装后先配置一个模型并选择角色，在故事页唤醒。观察首次准备、启动到健康状态的连续过程；全程无需进入维护面板。
2. 更新旧版 APK 后，唤醒自动更新组件，确认旧剧情与模型密钥保留。
3. 首次准备中切换 Tab、取消准备，确认取消后不会自行启动；再次点击可重试。
4. 无效模型地址、空间不足、启动失败时可以读取错误并重试；不显示虚假的在线状态。
5. 运行时修改温度、模型分工后失焦，点击重启生效；验证新参数进入宿主，旧故事与输入草稿保留。
6. 连续切换角色，确认消息、记忆、心绪来自对应故事；观察前台服务重启没有被旧服务销毁回调误停。
7. 验证系统通知停止、后台恢复、软键盘、安全区与 16 KiB 页设备。QQ 在核心重启期间也会断开，应检查重新连接状态。
