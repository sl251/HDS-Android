# Preview 7 · 让故事继续

版本：0.1.0-preview.7，Android versionCode 14。基线为 preview6 提交 `8fc9b20`，独立分支 `codex/preview7`，没有以 preview6.1 / 6.2 分支为父提交。

## 使用方式

- 故事页点击角色名切换故事；点击唤醒自动准备本机组件并启动。唤醒前可写草稿，完成后自动聚焦输入框。
- 空间按模型与识图、故事与身份、界面与阅读、存档与故事管理、核心维护分层折叠。模型任务选择和连接编辑继续分开，失焦保存；需重启的配置保留一键重启入口。外观实时生效。
- 图片理解可沿用支持图片输入的主叙事模型，也可选择独立连接：独立模型描述画面，主叙事收到文字观察后续写。支持 OpenAI 兼容及 Anthropic 连接；具体模型必须支持图片输入。
- 故事输入框可附加最多 3 张照片，允许仅发送图片。手机端压缩并校正照片方向，附件随故事保存在本机；发送会将图片提交给配置的模型服务商。发送失败保留附件、文字和请求编号，重试不重复入账。
- 界面采用半透明面板、浮动胶囊导航和玻璃边缘高光；可导入背景，调整图片不透明度、面板不透明度与模糊程度，支持系统/浅色/深色主题及字号。旧 WebView 没有模糊支持时仍可正常阅读和操作。

## 原版机制与移动端入口

核对原版 [HDS rc51 管理命令](https://github.com/ISEKAI-MomoiCore/HDS-Interlude/blob/9a77fadb88c6e57914ebac8ca75cf54a27354d01/command.md) 和 `src/service.ts`，不改变原版叙事和记忆算法。

| 原版机制 | Preview7 入口与范围 |
| --- | --- |
| `interlude.compact` | 见闻 → 长期记忆 → 立即整理记忆；复用 `compactStory`，会调用模型 |
| `interlude.memory.add` / `forget` | 补充事实、查看来源、停用事实；原始对话仍在，可能再次形成同一事实 |
| `interlude.memory.cancel` | 约定与待办 → 取消待办；复用 `cancelAdminIntent`，只处理当前故事仍等待的条目 |
| `interlude.overlay.clear` | 清理角色性格、视角、关系、世界或全部演化；复用 `clearSettingOverlay`，不删除对话和记忆 |
| `interlude.pause` / `resume` | 见闻暂停/恢复；保留历史 |
| `interlude.reset` / `database.clear` | 空间 → 存档与故事管理 → 从当前人设重新开始。移动端先正常关闭核心，再替换当前角色独立数据目录，旧目录保留为本机备份；新故事不读取旧记忆、关系、待办和图片 |

重开与原版直接清表的实现方式不同：手机每个角色有独立目录，采用目录替换便于恢复。其他角色、模型密钥、QQ 登录和公共 QQ 信箱保持原状。可导出完整 ZIP 存档，也可恢复本角色存档或最近本机备份；恢复后保持暂停。存档可能包含私密故事与图片，不包含模型密钥或 QQ 登录。此入口不是物理抹除，旧内容仍在备份里。

本版没有加入批量跨角色清库、分享码预设回滚或任意时间段删除。不要把“停用事实”理解为彻底遗忘；要从空白故事开始请使用“重新开始”。

## 实现边界与回归

在 preview6 上重新组合图片、外观与存档模块，复用已有版本中经过复核的独立实现，并保留旧图片字段规范化、背景缓存更新、存档中断恢复等修复。没有整分支合入 6.1/6.2。

新增检查发现图片采样需要显式设置 `BitmapFactory.Options.inSampleSize = 1`，否则默认值可能在压缩路径触发除零；已修复并添加 Android 仪器测试。停止、角色切换与重启等待正常保存确认，避免慢模型仍在写作时强制切走。

本地验证：TypeScript/Vite 构建；真实 Koishi/HDS/SQLite 的模型、附件与记忆测试；浏览器夹具覆盖自动保存、独立识图选择、纯图片失败重试、旧消息结构、背景保存重载、操作确认及 320/390/740px 浅深色布局。浏览器模拟原生桥接，不等于真机验收。Android 编译、lint、单元测试、签名 APK 与 ARM64 PRoot/QQ 检查由 GitHub Actions 执行，状态以该分支 Actions 为准。图片仪器测试需要 Android 设备实际运行。

视觉参考：[Mael-667/Liquid-Glass-CSS](https://github.com/Mael-667/Liquid-Glass-CSS) 的分层高光与背景模糊思路。本项目自行编写样式，不引入其 JS 或 SVG 折射滤镜，减少 Android WebView 的兼容与滚动开销。
