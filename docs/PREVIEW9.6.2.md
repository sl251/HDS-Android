# HDSI Android 0.1.0-preview.9.6.2

本版修复图片生成结果解析与渠道兼容，并补齐生图任务诊断。Android versionCode 为 **34**，包名与历史预览版签名保持一致，沿用 9.6.1 的 v2 + v3 签名方案。

## 生图修复

- 修复 Imagefree 已完成任务的 `image` 字段漏读，避免成功后继续轮询；免费队列最多等待 15 分钟，站点要求验证时显示明确原因。
- 「空间 → 语音识别与生图」新增接口格式选择：自动识别、OpenAI Images、聊天式生图、Gemini 原生。旧配置默认自动识别；Gemini image / Nano Banana 中转默认使用聊天式请求，完整端点和手动设置优先。
- 支持 URL、Base64、Data URI、Markdown 图片、聊天图片数组、Gemini 多段图片及聊天网关 SSE 响应。参考图按渠道发送 multipart、image_url 或 inlineData；DALL·E 与 GPT Image 使用对应尺寸。
- 不会在失败后自动切换协议重新提交。明确拒绝的请求可修正配置后重试；提交结果不明时阻止重复生成；投递失败只重试已保存图片的投递。

## 生图诊断

- 记录准备、提交、查询、下载、保存和投递阶段，以及渠道类别、接口格式、HTTP 状态、耗时和分类原因。
- 异步生图保留原消息关联；头像和动态任务无需聊天消息也能查看。失败筛选包含生图任务，聊天与动态页提供失败入口。
- 自主生图因配置、意愿或冷却被跳过，以及任务创建失败，也会留下记录。诊断不保存密钥、提示词、参考图、原始响应或下载链接；清空后在途结果不会重新写回。

## 验证与使用边界

- 完整宿主回归、专门的生图协议与任务回归、前端类型检查和构建，以及设置和诊断浏览器回归均纳入验证。
- 发布流水线执行 Android 编译、lint、原生单元测试、签名与校验，以及实际 ARM64 运行环境 / QQ 无账号冒烟检查；两组构建检查成功后才发布 APK。
- 生图协议与错误场景使用模拟服务响应验证。本次未执行付费服务真实生图、参考图实测或 Android 真机安装；服务商兼容性与 Imagefree 验证策略仍需按实际渠道确认。
