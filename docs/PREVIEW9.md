# Preview 9 · 角色自主表情包、自主语音与音色工作台

版本：`0.1.0-preview.9`，versionCode 19，2026-10-17 发布。

## 版本定位

**HDS-Android Preview 9** 是一次聚焦于角色沉浸表达与互动体验收敛的重大更新。在打磨消息状态（已读双勾、正在输入、失败重试）、重构设置结构与输入交互的基础之上，本版本正式引入了**角色自主表情包**与**角色自主语音**两大核心表达能力，并配套上线了便捷的**音色工作台**。AI 伴侣不再只是单调的文字输出，而是能根据语境自主选择合适的情感表达——在需要时发出灵动的表情包，或用熟悉温暖的真实声线轻声倾诉。

---

## 🎭 角色自主表情包

### 1. 贴纸库导入与管理
- **面板入口**：在输入框点击表情图标即可展开贴纸抽屉面板。
- **导入方式**：支持单张/多张图片多选导入，更支持整文件夹通过 SAF（系统存储访问框架）一键导入（文件夹名称将自动作为贴纸包名）。
- **格式与去重**：支持 GIF、PNG、WebP、JPEG 格式图片，导入时自动校验与去重过滤。
- **包管理**：贴纸面板内支持对贴纸包进行重命名与删除；贴纸包按最近使用自动排序，全局共享贴纸库。

### 2. 角色如何使用表情包
- **语境驱动自主发送**：底层将贴纸清单（编号及情绪标签）动态注入到提示词中，角色会像真人聊天一样，在适宜的情感语境下自主挑选并附带贴纸标记。
- **无气泡原生渲染**：消息流中角色发送的贴纸直接去除外层卡片气泡原生呈现，更加清爽生动。

### 3. 空库兜底机制
- **零语法侵入**：当贴纸库为空时，系统**完全不向提示词注入任何贴纸标记语法**，避免模型生成未定义标记。
- **静默降级**：前端解析层若收到未知或解析异常的贴纸标记，会自动剔除并降级为纯文本，确保对话绝不乱码。
- **UI 自动收起**：在尚未导入任何贴纸时，输入框旁边的表情入口会自动隐藏，保持界面极简。

## 🎤 角色自主语音

### 1. 开关与音色绑定
- **独立开关**：在对应角色的设置页面中提供了专属的语音开关，开启后角色即可开始使用语音表达。
- **音色绑定**：每个角色均可独立绑定音色工作台中保存的专属音色。

### 2. 语音意愿与冷却
语音在 HDS 中是角色的自然表达手段，而非机械化地字字朗读。
1. **意愿阈值**：模型通过内置意愿判断，只在情绪浓烈、特定剧情节点或适合倾诉时才主动发起语音。
2. **发送冷却**：设有最小发送间隔冷却，防止角色连续多句频繁发送语音打扰阅读。

> 自 Preview 9.4 后续修复起，已删除本机每日语音 Token 预算和预扣记账；这不改变语音服务商自己的配额或限流规则。

### 3. 语音气泡与文字稿
- 消息流中伴随生动的语音播放气泡，支持点击播放与进度显示。
- 语音消息始终附带文字稿，即便在静音环境或不便外放时也能一目了然。

### 4. 失败静默降级
- 若遇到网络波动、接口超时或 TTS 生成失败，系统将**静默降级**为原本的纯文字消息正常呈现，绝不阻塞对话主流程。

## 🛠️ 音色工作台

音色工作台是为角色定制专属声线的创作中心：
- **入口位置**：底部导航切换至「空间」板块，进入「音色工作台」。
- **录音克隆**：直接使用手机麦克风现场录制一段人声音频（最长 60 秒），系统即时克隆生成音色特征，免去漫长的训练等待。
- **导入克隆**：支持从手机本地导入现有的参考音频文件（支持 `.mp3`、`.wav` 格式，时长 ≤180 秒、10 MiB 以内）。
- **文字描述设计**：支持通过自然语言文字描述角色的声线特质（如性别、年龄感、语气、音质氛围等），直接生成贴合设定的全新音色。
- **音色管理**：工作台内支持一键试听音色效果、重命名音色、绑定到指定角色卡，以及清理删除无用音色。

## 🔑 密钥获取与接口说明

- **平台地址**：请前往 [小米 MiMo 开放平台](https://platform.xiaomimimo.com) 注册并登录。
- **创建密钥**：在控制台创建 API Key（密钥格式为 `sk-xxxxx`），TTS 服务端点为 `api.xiaomimimo.com`。
- **免费政策**：小米 MiMo 开放平台的语音模型（包含 `mimo-v2.5-tts`、`mimo-v2.5-voiceclone` 与 `mimo-v2.5-voicedesign`）目前均处于**免费开放使用**阶段。
- **厂商兼容说明**：当前 Preview 9 版本**仅适配了小米 MiMo 的 TTS 接口**，其他厂商（如 OpenAI、MiniMax 等）的语音接口暂未接入。

## 🔮 下一步计划

Preview 9 完成了角色表达维度从文字到图文与声音的拓展，后续版本将持续推进以下方向：
1. ⌨️ **优化输入体验**：进一步完善移动端键盘输入手感、快捷交互与发送响应。
2. 🎙️ **适配更多 TTS 模型**：接入更多主流云端语音厂商与本地开源 TTS 引擎。
3. 🗣️ **增加 STT（语音转文字）功能**：支持用户端语音输入并转写，实现真正的对话往来。
4. 📞 **增加语音通话功能**：探索端到端低延迟的双向实时语音通话模式。
