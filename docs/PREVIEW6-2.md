# Preview.6.2 测试版

本版延续 preview.6 的本地 HDS / SQLite / QQ 架构。

## 已实现

- 空间按模型、故事身份、界面阅读、存档和维护分组折叠。模型任务分工、连接编辑、生成/识图参数分别折叠；添加或选择连接时展开编辑。
- 全局外观：字体预设、本地 TTF/OTF、12–24 px 阅读字号、背景图片、不透明度、面板不透明度、背景模糊、系统/浅色/深色主题与恢复默认。资源保存于应用私有目录，外观修改即时生效且单独持久化。
- App 故事聊天支持至多 3 张图片与文字一起发送，也支持纯图片。原生层压缩到最长边 1024，历史保存本机图片编号并按需加载，点击查看大图。需要在模型 → 生成、识图与备用切换中开启“主模型识图”，使用支持视觉的模型并重启。QQ 发图未加入本版。
- 见闻 → 长期记忆：补充事实、停用事实、查看来源、立即整理。停用保留审计记录及原始经历，不承诺彻底遗忘；整理可能调用模型。长操作返回任务编号并轮询。
- 当前角色 ZIP 存档导出与恢复，包括完整数据库、图片、角色卡与 profile 附属文件；不包含模型密钥或 QQ 登录。先验证角色、格式、路径和校验和，再停止核心并替换 profile。
- 当前角色重新开始：等待正常保存，备份旧 profile，创建空 profile，保留当前卡和 QQ 白名单；其他角色与公共 QQ 登录/信箱保留。恢复/重开后故事保持休息；存档恢复后的首次唤醒仍暂停，需要在见闻明确恢复。
- profile 替换使用操作日志；未完成的操作在下次应用初始化时恢复旧故事。内嵌核心添加窄范围的事实维护方法，并清理旧任务和连续性快照。

## 测试重点

1. 用同签名 APK 覆盖安装，检查旧角色、聊天、模型密钥和 QQ 登录仍在。
2. 检查全部设置折叠、添加连接自动展开和失焦保存。外观变化无需重启 HDS，模型参数仍需重启。
3. 导入中文 TTF/OTF，调整字号、深色主题、背景与透明度；杀掉 App 再打开，确认保存。字号较大时检查小屏幕和键盘。
4. 选择一张手机照片，检查方向、预览、移除、纯图片、图片加文字、失败后草稿和图片保留、重启后历史大图。
5. 使用视觉模型测试图片内容识别；文本模型不可用时应显示真实失败，不宣称角色已看懂。固定模型测试不等于实际供应商识图验收。
6. 补充明确事实、查看来源、停用，确认有效事实列表更新；整理操作只执行一次，超时后继续查询任务。
7. 导出 ZIP 后进行重开，再恢复 ZIP；检查聊天、图片、事实、心绪、人设与未完成事项。恢复后检查暂停状态，再明确恢复。
8. 在模型生成时尝试导出/重开，观察等待正常保存；空间不足、取消文件选择和损坏存档不能破坏原故事。
9. 文件操作后核心保持停止，请重新唤醒。已发送到真实 QQ 的消息不会撤回；公共 QQ 信箱不属于角色存档。
