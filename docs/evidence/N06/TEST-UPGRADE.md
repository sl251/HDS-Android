# preview.2 覆盖升级验证

1. 保留 preview.1，不卸载、不清数据。安装同签名 preview.2 候选，启动后检查已有角色、当前选择和剧情。
2. 打开设置，先“保存诊断”。报告包含设备、WebView、页大小、文件/硬链接/符号链接探针与各自 errno，不包含模型密钥、人设或聊天。
3. 旧环境准备失败时点“准备本机环境”或“重试准备”；旧环境成功安装过时点“更新本机环境”。本次环境必须重新准备，避免继续使用旧 host。
4. 环境文件就绪后，选择角色、保存模型设置，再启动 HDS。分别确认 Node/PRoot、SQLite、HDS 健康；解包成功不代表这些步骤已经通过。
5. 发一条本地消息，停止、重启，确认剧情与聊天保留；真实模型连接测试由用户在 App 主动点击。
6. 安装过程中点击取消，再重试；重复点击不能双重安装。强停后手动返回 App，检查原环境或新环境的一代一致性。
7. 设置、聊天、角色预览在竖屏/横屏、手势/三键、大字体下截图；状态栏不遮挡标题，键盘出现时输入、发送和保存可达。诊断中的 layout 字段可与截图时间对齐。
8. 如果失败，保存诊断并提供失败阶段/条目/errno。不要用“停止”代替修复，不要求 Root 或共享存储权限。

iQOO 15、旧 Android、16 KB 页、后台存活、SAF 取消/短写/权限失效均为 NOT RUN，待手机验收。仪器测试 APK 在 Android 工程的 debug/androidTest 输出，需要 ADB 安装配套 debug App；它不代替同签名 release 的覆盖升级验收。
