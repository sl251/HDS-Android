# HDS-Android Preview 9.5.3

本次发布合并 PR #19，在聊天中加入按真实处理状态显示的角色“正在输入”气泡，并在空间中集中管理模型任务分工。可分别指定主叙事、记忆压缩、心理分析、世界播种、图片识别、向量检索和重排序连接。

旧向量连接、模型名与端点保持原值；新任务选择继续同步兼容标记。记忆和表情包入口统一跳转到任务分工。输入状态在回复投递、不回复、延迟回复、失败、核心停止或查询过期时收起，并支持系统减少动态效果。

应用版本：`0.1.0-preview.9.5.3`；Android versionCode：31。保持 HDS rc57 基线，包名与预览版签名不变。此 APK 为 ARM64 开发预览版。真机安装、模型服务与 QQ/语音实际收发仍需按 `docs/TEST-ON-PHONE.md` 验收。
