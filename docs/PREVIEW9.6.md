# Preview 9.6 · 聊天、动态与角色媒体体验

- 聊天支持流式输出，发送失败与回复失败可从原消息重试；连续消息可等待合并后再回复，回车发送/换行可设置。
- 聊天新增相机拍照、相册发送、点按/按住录音、试听与语音转文字。STT 独立配置，未转写的语音有明确提示。
- 底部「信箱」换为按故事隔离的「动态」，用户与角色可发帖、点赞、评论；角色知道互动变化，并自主决定是否回应。「分享此刻」默认折叠，信箱与 QQ 入口移到空间。
- 支持独立生图服务与 Imagefree 渠道。自拍、聊天图片与动态配图由角色自主决定，支持固定外观、画风、衣装、参考图与生成间隔。
- 「角色头像」独立于角色视觉档案，可从相册上传任意图片或按人设生成；用于聊天和动态，未设置时聊天保持原样，不会把头像自动作为生图参考图。
- 增加通知形式、内容预览、应用内横幅与安静时段设置；悬浮、声音和振动遵循 Android 系统通知权限与渠道。
- 空间设置增加留白，整合重复的流式/消息合并入口；增加五种主题配色，表情包设置跟随主题，优化底部导航光条。
- 修复天气缓存的坐标与地点隔离、故事恢复后的录音读取，并为媒体任务增加幂等与中断恢复处理。

支持 ARM64 / Android 8.0 及以上，沿用原签名，覆盖安装前建议备份故事，请勿先卸载。媒体服务默认关闭；真实 STT/生图能力取决于所选服务，Imagefree 如要求验证不会绕过，也不会自动转用收费渠道。系统相机、录音、通知及真实模型服务仍需按设备与服务配置验收。
