# Preview 9.3 后续优化验证

日期：2026-10-19。基线 `8e0ae09`，提交与合并入口：[PR #15](https://github.com/sl251/HDS-Android/pull/15)。最终 Linux CI 结果及完整日志见该 PR 的 `regression` 检查；合并前须通过该检查。

## 补测发现并修复

- 重复提交已完成消息、正常结束的不回复回合，会在重启时误报中断。恢复扫描现在识别已结束状态，重复接收不覆盖原回合状态。
- 到期延迟回复会生成新的故事记录；原实现只关联了原记录。现在沿已保存计划中的 `scriptEvent.scriptEntryId` 进入到期回合，把新记录继续关联至原请求；不按文本或时间猜测，也不增加模型调用。
- Windows CRLF 导致补丁文件名和替换锚点失配。补丁读取及回放统一换行；原始上游源码保持不变。
- 旧测试中的已读推断、共享表情包默认导出、设置入口和默认折叠断言已按新行为更新。Linux 专用 `/proc` 与进程组测试在 Windows 明确跳过，Linux CI 完整执行。

新增和扩展的用例验证：
