# HDSI Android 0.1.0-preview.9.6.3

本版修复 9.6.2 生图任务被旧渠道配置检查拦截的问题。Android versionCode 为 **35**，包名与历史预览版签名保持一致，沿用 v2 + v3 签名方案。

## 生图配置与任务恢复

- 尚未提交的排队任务使用执行时的最新渠道设置，切换 Gemini、Imagefree 等渠道后不再误报 `media_configuration`。
- 已提交的 Imagefree 任务继续查询原渠道；已取得图片地址的任务直接下载。恢复任务不使用新渠道的密钥，也不重新提交生成请求。
- 旧版本因配置检查失败的任务可从原有重试入口继续处理，无需来回切换渠道。
- 明确未提交或被服务拒绝的自主生图失败不再占用冷却时间；成功、在途和提交结果未知的任务继续受冷却与防重复提交保护。
- 重启时，标记为已提交但没有结果的排队任务转为结果未知，避免重复生成；诊断提示同步更新。

## 验证

- 新增 5 个配置切换、旧任务恢复与自主生图冷却回归用例；发布流水线运行完整宿主测试、前端构建、设置和诊断 UI 回归。
- 发布流水线在 Android 编译、lint、原生单元测试、签名校验和实际 ARM64 运行环境 / QQ 无账号冒烟检查通过后，发布 APK、源码和 SHA-256 校验清单。
- 本地已通过用户提供的 Gemini 聊天式渠道及 Imagefree 分别完成真实生成、下载与保存，详情见 [生图配置修复记录](IMAGE-ROUTE-FIX.md)。本轮未验证 Android 真机聊天投递、参考图或真机覆盖安装。
