## 🌟 项目简介

**HDS-Android** 是专为 Android 打造的 HDS-Interlude 移动端独立运行器。

以往要在手机上体验 HDS，往往需要复杂的电脑端服务器中转，或者在手机里通过 Termux 手动敲 Linux 命令行部署。**现在，这一切只需安装一个 APK 即可搞定！**

- **真正纯本地**：手机内置轻量运行沙箱（PRoot + Node.js + SQLite WASM），所有角色卡、人设演化、对话历史与长期记忆**完全保存在你的手机本地**。
- **隐私与安全**：模型密钥经由 Android Keystore 硬件级加密保存；AI 仅作为大脑，记忆归你所有。
- **当前测试版本**：**`0.1.0-preview.5.4 · ARM64 · Android 8+`**。经过真机实测验证，核心叙事与本地 QQ 互动均已稳定跑通！👉 [**直达下载 preview.5.4 安装包**](#第一步安装应用)

## 🚀 5 分钟极速上手教程

按照以下顺序操作，几分钟即可开启与角色的故事：

```mermaid
flowchart LR
    A["1. 安装 APK"] --> B["2. 准备本机环境"]
    B --> C["3. 配置模型中心"]
    C --> D["4. 导入角色卡"]
    D --> E["5. 启动 HDS 畅聊"]
    E -. 可选扩展 .-> F["6. 扫码接入 QQ"]
```

### 第一步：安装应用

从下方链接下载经真机实测验证的 **preview.5.4** 安装包：

- 📦 **直接下载构建产物**：前往 [preview.5.4 Actions 构建详情页 (Run #38434506843)](https://github.com/sl251/HDS-Android/actions/runs/38434506843)，在页面底部的 **Artifacts** 列表中点击下载 `HDS-Android-preview-7d13134...`（解压即可得到 `HDS-Android-0.1.0-preview.5.4-arm64.apk`）。
- 🏷️ **GitHub Release**：也可前往 [v0.1.0-preview.5.4 Release 页面](https://github.com/sl251/HDS-Android/releases/tag/v0.1.0-preview.5.4) 直接下载 APK。

> [!IMPORTANT]
> **覆盖安装注意事项**：若手机已安装旧版本，**请直接覆盖安装，千万不要先卸载**！卸载会导致手机内的历史剧情和角色数据库被系统清除。

### 第二步：初始化本机环境
打开 App，进入底部的 **「设置」** 页面，点击 **「准备本机环境」**。  
App 会自动在手机私有存储中校验并解包运行所需的基础组件（耗时约 1~2 分钟，仅首次使用或大版本升级时需要执行）。

### 第三步：配置 AI 模型
在 **「设置」** 页面下的 **「模型中心」** 中：
1. 点击添加或选择预设供应商（如 DeepSeek、OpenRouter 等），或填写自定义 Base URL。
2. 填入你的 **API Key**（数据将安全保存在本机 Keystore 中）。
3. 点击 **「获取模型列表」** 选择模型，或直接手动输入模型名称。
4. 为 **主叙事**、**记忆压缩**、**Alter** 分配对应的模型连接。
5. 点击 **「测试当前连接」**，确认网络与模型调用通畅，随后点击 **「保存全部设置」**。

### 第四步：导入心仪的角色卡
切换到底部的 **「角色」** 页面：
- 点击 **「导入角色」**，直接选择你的酒馆角色卡（`.png` / `.json`）或 typ0 下载的 `koishi.yml`。
- 预览人设信息、世界书与开场白，确认无误后保存并选中为当前角色。

### 第五步：启动 HDS 并开始对话
1. 回到 **「设置」** 页面，点击 **「启动 HDS」**，等待状态切换为绿色的 **“运行中”**。
2. 切换到底部的 **「对话」** 页面，发送消息即可开启互动！
3. 在对话页可随时查看由 HDS 动态生成的真实剧情分支、事实档案与长期记忆。

## 💬 进阶玩法：手机本地 QQ 接入（信箱）

无需电脑挂机，不用云服务器，让角色直接成为你的 QQ 好友：

1. **准备组件**：确保 HDS 处于运行状态，切换到底部的 **「信箱」** 页面，点击 **「下载并准备组件」**（初次使用需下载约 235 MiB 组件，请保证手机至少留有 1.6 GiB 剩余空间）。
2. **启动与扫码**：点击 **「启动 QQ」**，等待二维码生成后，使用**手机官方 QQ 扫码授权登录**。
3. **确认通道在线**：等待信箱状态变为 **“QQ 与 HDS 消息通道已连接”**。
4. **安全白名单设置**：
   - 为避免无谓的模型 API 消耗与风控，**自动回复默认关闭**。
   - 点击 **「角色自动回复」**，在白名单中填入允许互动的 **QQ 好友账号** 或 **QQ 群号**。
   - 开启自动回复开关：白名单内的好友私聊将自动得到当前角色的回复；群聊中**仅在被 @ 时**才会触发角色回复。
5. **双向信箱互动**：在信箱页面可随时查看互动记录，也可以用当前登录的 QQ 身份手动给好友发送消息。

> [!TIP]
> 切换角色时，QQ 登录凭证依然保存在本机独立区域；再次启动 QQ 可直接快捷登录，不同角色的白名单彼此独立。

## 📱 界面布局简介

应用采用沉浸式纸墨质感风格，底部导航分为四大板块：

- 📝 **对话**：与当前角色的主对话界面，并可在此展开查看角色的长期事实、故事脉络与心理状态。
- 📬 **信箱**：本地 QQ 运行状态看板、扫码登录入口、消息流查阅与手动发信。
- 🎭 **角色**：角色的导入、人设微调、切换与管理。
- ⚙️ **设置**：本机环境管理、HDS 核心运行开关、多模型中心与网络连接测试。

## ⚠️ 使用建议与系统要求

> [!NOTE]
> - **系统支持**：Android 8.0 及以上，仅支持 **ARM64** 架构（绝大部分现代安卓机型均适用）。
> - **存储空间**：基础运行建议预留至少 **1.5 GB** 空间；若启用 QQ 组件，建议额外预留 **1.6 GB** 空间。
> - **后台保活建议**：由于手机系统（如 HyperOS、OriginOS、ColorOS 等）对后台进程管理较严格，若想在锁屏或退回桌面后角色仍能持续思考、回复 QQ，请在系统设置中：
>   1. 将本应用加入**允许自启动 / 允许后台活动**白名单；
>   2. 将电池策略设置为**“无限制 / 不优化”**；
>   3. 在多任务后台给应用挂上**“锁定后台”**的小锁。
> - **QQ 安全规范**：建议使用小号进行测试，遵守相关平台规范；请务必合理配置白名单，避免在大型陌生群聊中频繁触发。

## 🛠️ 常见问题解答 (FAQ)

<details>
<summary><b>Q1: 为什么点击“启动 HDS”后一直卡在启动中或报错？</b></summary>

1. 请先检查手机空闲存储空间是否充足。
2. 检查「设置」中的「模型中心」，是否为主叙事、记忆压缩、Alter 分配了有效的模型，并点击「测试当前连接」确认 API 能正常连通。
3. 若仍无法启动，可点击状态栏下方的展开日志，查看具体报错信息；对于特定系统（如 OriginOS），preview.5.1 已包含 PRoot seccomp 探测修复。
</details>

<details>
<summary><b>Q2: 升级新版本后，我之前的人物故事和聊天记录会丢吗？</b></summary>

只要你**直接覆盖安装**同签名的 APK，所有数据库、人设文件、模型设置及 QQ 登录态都会完整保留。**千万不要卸载后重新安装**，安卓系统在卸载应用时会删除该应用在私有目录中的全部数据。
</details>

<details>
<summary><b>Q3: 修改人设卡信息后，之前的记忆会重置吗？</b></summary>

不会。修改人设后重启 HDS，系统会调用原生的更新机制应用新的性格/设定描述，但角色原有的故事发展脉络、已沉淀的记忆库与关系历程会完整保留。
</details>

<details>
<summary><b>Q4: QQ 扫码后为什么没有自动回复？</b></summary>

为了保护你的 API 额度，自动回复**默认是关闭的**。请前往「信箱」->「角色自动回复」，开启自动回复开关，并将对方的 QQ 号（或所在群号）加入白名单列表。在群聊中，角色只有在被 `@` 时才会触发回复。
</details>

## 💻 开发者编译与构建

如果你想自行编译或向本项目贡献代码：

```sh
# 1. 安装前端与工作流依赖
npm ci --ignore-scripts
npm test

# 2. 同步资源至 Android 工程
npm run android:sync

# 3. 构建/准备运行时文件
python3 scripts/build-runtime.py

# 4. 构建 Release APK
cd android
./gradlew lintRelease testReleaseUnitTest assembleRelease
```

- **推荐构建环境**：Linux x86_64 / ARM64, Node.js 24.11.1, Python 3.12, OpenJDK 21, Android SDK 35。
- 完整打包流程建议参考项目的 GitHub Actions 工作流配置文件。
